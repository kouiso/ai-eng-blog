## 読み終えた人ができるようになること

モデルが渡したパスを、作業フォルダの中にあり、許可した種類と大きさのファイルのときだけ開くツールの関数を TypeScript で書き、`tool_result` の形でエラーを返せる。

## 書き手の態度（guides/03 不在1）

守りの本体は `path.relative` と `realpath` の2つで、`startsWith` の比較と `path.isAbsolute` は守りにならない、という判断を記事の軸にした。どちらも実行結果（`run/03.log` の `readWithPrefixCheck`、出典1 の Node.js の注意書き）で裏付けた。防げないこと（リンクの差し替え、ハードリンク）も隠さずに書く。
