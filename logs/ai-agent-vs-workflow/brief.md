# brief: ai-agent-vs-workflow

## C01 の1行

LLM の API を少し触った TypeScript の開発者が「AI エージェントとワークフローの違い」を調べたときに、次の手順を決めるのがコードか LLM かという違いを、同じ仕分けを2通りに書いて動かした実測（呼び出し回数、時間、見積もりの費用、途中で止める仕組み）つきで答え、どちらを選ぶかの判断基準を示す記事。

## 検索意図のタイプ

概念（Learn）。違いの比較（Compare）の要素もあるが、読者が知りたいのは「エージェントとは何で、ワークフローと何が違い、いつ使うか」なので、型は解説記事にする。

## 読み終えた人ができるようになること

自分の処理をワークフローとエージェントのどちらで書くかを、手順を先に書き出せるかで決め、Agent SDK の `query()` で両方を書ける。

## 態度（guides/03 不在1）

手順を書き出せる処理はワークフローで書く。実測ではエージェントのほうが速くて安かったが、それでもこの仕分けはワークフローにする。理由は呼び出し回数が先に決まり、手順の間で答えの形を確かめられるから。
