この記事での見出し（作業の実況ではなく、内容で書く。guides/02 共通原則4）:

1. リード（`includePartialMessages: true` で途中の文字が届く、最初の文字と全文の時刻の実測、プランで動く、前の記事へのリンク）
2. 前提は Node.js 22.18.0 以上と、プランでログインした Claude Code（`ANTHROPIC_API_KEY` を外す、プランで動かしてよい範囲）
3. SDK は 0.3.322 に固定して入れる
4. includePartialMessages を true にして text_delta を書き出す（`stream.ts`）
5. 届く順番と時刻を timing.ts で確かめる（`timing.ts`）。小見出しで、差分の個数と間隔、thinking のブロック、assistant と result の位置
6. ストリーミングで縮むのは、最初の文字が出るまでの待ち時間（判断。画面は `text_delta`、保存は `result`）
7. 料金、出典、次の記事へのリンク、末尾の表記

所要時間の目安は書いていない。実測していないため。

## 読み終えた人ができるようになること

Agent SDK の `query()` に `includePartialMessages: true` を渡し、`stream_event` の中の `text_delta` だけを取り出して届いた順に表示できる。`assistant` と `result` がいつ届くかを知り、画面と保存で使う値を分けられる。
