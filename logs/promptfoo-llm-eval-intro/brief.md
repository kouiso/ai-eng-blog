この記事での見出し（内容で書く）。

1. リード（promptfoo とは何か、何を比べるか、実行して何が起きたか）
2. 用意するのは Node.js 22.22.0 以上と、Claude Code が使えるプラン（前提・環境。プランで動かす範囲の注意）
3. npm install で promptfoo と Agent SDK を入れる（手順1。npm audit の警告の扱い）

5. npx promptfoo eval の表で、形を指定しないプロンプトが3件とも FAIL になる（手順3。動作確認と終了コード 100）
6. 不合格の理由は results.jsonl から読む（手順4。2回目の実行との比較）
7. 1回の評価で、プランの利用枠から6回分が引かれる（料金。キャッシュが効かないこと、システムプロンプトの差）
8. ほかの人に使わせるなら API キーで動かす（プランの利用範囲）
9. 出典、次の記事、AI 支援の表記

## 読み終えた人ができるようになること

promptfoo の設定ファイルに prompts、providers、tests、assert を書き、自分の Claude プランで評価を実行して、表と results.jsonl から不合格の理由を読み、終了コードで合否を判定できる。

## 態度（guides/03 不在1）

分類の中身が合っていても、受け取る側のコードが扱えない形の答えは不合格にする。プロンプトの比べ方として、形の検査（regex）と中身の検査（icontains）を分けて書くと、どちらで落ちたかが表で読める。
