手元の資料を毎回会話に添えたいだけなら、ツールより Resource が向いている。どの機能にするかは「誰が使うか」で決める。SDK の not found のコードが仕様の推奨と食い違う点と、Claude Code が Prompt の引数を空白で分ける点は、読者が実際に引っかかる所として書く。
