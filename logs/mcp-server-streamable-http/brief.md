# brief: mcp-server-streamable-http

## C01 の1行

stdio の MCP サーバーを TypeScript で1つ作ったことがあり、次に HTTP で受けるサーバーにしたい開発者が、公式 SDK v1 系で Streamable HTTP のサーバーを書く方法を検索したときに、手元（127.0.0.1）で動くサーバーのコード一式、SDK のクライアントと curl での確かめ方、仕様が求める Origin の検査、つまずく2か所（トランスポートの使い回しで 500、GET に 405 を返さないとクライアントがエラーを報告）を、実行結果つきで答える記事。

## 書き手の態度（guides/03 不在1）

いちばん大事なのは、1回の HTTP リクエストごとにサーバーとトランスポートを作り直すことと、Origin の検査を自分で書くこと。どちらも書き忘れても手元のクライアントでは気づきにくい（使い回しは2回目から空の 500、Origin はブラウザからしか届かない）。そこを長く書き、ツールの中身は前の記事に任せて短くする。

## 読み終えた人ができるようになること

公式 SDK v1 系で、自分のツールを Streamable HTTP（ステートレス）のサーバーとして 127.0.0.1 で動かし、SDK のクライアントと curl と Claude Code から呼べたことを確かめられる。公開する前に何が足りないか（公開 URL、HTTPS、認証、Origin の許可リスト）を言える。
