# keywords

ラッコキーワードで調べた結果の CSV を置く場所です。記事を書く `write-article` スキル（`.claude/skills/write-article/SKILL.md`）が、ここから次に書く1語を選びます。ユーザーはラッコキーワードにログインするだけで、CSV の書き出しと、そこからのキーワード選びは Claude が行います（画面の一覧をプログラムで写し取ることはしません）。

**CSV はコミットしません。** このリポジトリは public です。ラッコキーワードの利用規約（https://rakkokeyword.com/terms 、2026-08-24 改定版）は、取得したデータを第三者へ継続して提供するにはライセンスが要るとしています（第26条3項、第28条1項）。また、データの権利はラッコに残ると定めています（第29条1項）。public リポジトリに生データを置いてよいかははっきりしないため、扱いが決まるまで `keywords/*.csv` は `.gitignore` で除外しています。CSV はこのフォルダに手元でだけ置きます。受け渡しも public リポジトリを経由しない方法で行います。リポジトリに残すのは、`logs/<slug>/selection.md` に書く「なぜその1語を選んだか」の説明だけです。CSV の行をそのまま写すことはしません。

## Google のサジェストを集めた CSV

ラッコの CSV が無い間は、Google のサジェストを集めた CSV で記事のキーワードを選びます（オーナーの裁定 2026-11-11「最初はサジェストくらいのワードで反応見てみるのもありかな」）。Claude が自分で集めて、`keywords/google-suggest-<名前>.csv` に置きます。これもコミットしません。

| ファイル名 | 講座のキーワード |
|---|---|
| `google-suggest-llm-api.csv` | LLM API |
| `google-suggest-structured-output.csv` | 構造化出力 |
| `google-suggest-rag.csv` | RAG |
| `google-suggest-ai-agent.csv` | AIエージェント |
| `google-suggest-mcp-server.csv` | MCPサーバー |
| `google-suggest-llm-eval.csv` | LLM 評価 |

列は `suggestion,seed_query,rank,fetched_at` です。キーワード本体は `suggestion`、`seed_query` は入力した種の語、`rank` はその種で候補が出た順番です。検索ボリュームはありません。公開したあとは Search Console の実測で選び直します。

ラッコの CSV は、ラッコにログインした状態で、書き出しボタンから取得したものだけを置きます。画面に出た一覧をプログラムで写し取ることはしません（ラッコの共通規約 第19条がスクレイピングとそれに類する行為を禁じています。https://rakkoid.com/terms 、2026-11-11 確認）。

## 置き方

講座のキーワード1語につき CSV を1つ、`keywords/<講座のキーワード>.csv` の名前で置きます。講座のキーワードは入門ステップ講座の順番どおりの6語です。サイトの主キーワードは、サイトで1つだけで「生成AI API」です（2026-11-14 に、ラッコキーワードのサジェスト一覧と Google トレンド（日本、12か月）の比較から決めた。無料プランなので検索数は無い）。

| 講座の順番 | 講座のキーワード | ファイル名 |
|---|---|---|
| 1 | LLM API | `LLM API.csv` |
| 2 | 構造化出力 | `構造化出力.csv` |
| 3 | RAG | `RAG.csv` |
| 4 | AIエージェント | `AIエージェント.csv` |
| 5 | MCPサーバー | `MCPサーバー.csv` |
| 6 | LLM 評価 | `LLM 評価.csv` |

- ファイル名は講座のキーワードの表記と1文字も変えない。空白を含む名前があるので、シェルでは引用符でくくる。
- ラッコから落とした CSV は中身を編集せずに置く。文字コードの変換や列の並べ替えもしない。元のデータと、スキルがそれをどう読んだかを分けて追えるようにするため。
- 取り直したときは同じ名前で上書きする（CSV はコミットしないので、git の履歴には残らない）。

## スキルが使う列

スキルがキーワードを選ぶのに必ず使うのは、次の2列です。

| 用途 | 想定している列 |
|---|---|
| キーワード本体 | キーワードの文字列が入った列 |
| 検索ボリューム | 月間の検索数が入った列。任意（ラッコの無料プランには無い） |

検索ボリュームが無い CSV でも使えます。そのときの比べ方はスキルの手順に書いています。ほかの列（難易度の指標など）は必須ではありません。ラッコの CSV にあれば参考として使います。ただし、`logs/<slug>/selection.md` に書くのは選んだ理由だけで、行や値をそのまま写すことはしません。

ラッコキーワードの書き出しは、文字コードが UTF-16（BOM 付き）で、タブ区切りです。ヘッダーは `No, 区分, 単語数, キーワード, SEO難易度, 月間検索数, CPC ($), 競合性, 出現時期` です。キーワード本体は「キーワード」の列で、「月間検索数」は無料プランでは null です。
