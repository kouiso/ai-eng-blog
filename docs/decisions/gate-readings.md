## 使い方

- 書く AI は、手順8で該当する行を判定する前にこの文書を読む。
- 点検する AI は、原稿、`logs/<slug>/`、SKILL.md、checklist と一緒にこの文書を渡される（SKILL.md の「書く AI と点検する AI」）。
- 裁定とゲートの行、checklist、SKILL.md が食い違ったら、その行の判定を止めて issue に書き、マネージャーの判断を待つ。食い違いを解くとゲートが弱くなる場合は、オーナーに上げる。
- 新しい裁定が出たら、まず #81 のコメントか新しい issue に文面を残し、この文書に1項目足す。足すときは、規則、読む行、出典、根拠の行、日付を書く。
- 「オーナーが覆せる」と付いた項目は、オーナーへの報告に載せている項目で、オーナーの判断で変わることがある。

## 3. C25: 1文60字

- 規則: 自然な文は、置かれた場所に関係なくすべて数える。数えないのは、表のセル1つまたは frontmatter の値1つが、丸ごと URL 1つだけのとき（ASCII の RFC 3986 の文字だけ、値全体で一致）に限る。数えなかったものは `[SKIP C25-URL]` の下に並べ、件数を出す。URL に文字がくっついたもの（`URL（英語のページ）`、`URL、URL` など）は数える。リスト項目や本文の行が URL だけのときは、この裁定に入らない。出てきたら統括に上げる。
- 読む行: C25（`60字超の長文を分割した`）
- 出典: https://github.com/kouiso/ai-eng-blog/issues/81#issuecomment-6878197474 の3。
- 根拠: C25 の対象は文である。URL だけの値は文ではなく、直しようがない（#77 の突き合わせの裁定）。pack の lint の扱いは根拠にしない。
- オーナーが覆せる: 覆せる。
- 日付: 2026-11-14
- 補足: SKILL.md の「判定のために補助のスクリプトを書くときも、checklist とガイドに無い除外を入れない」に対して、値を数えない場所はここだけである。範囲はこの1種類に限る。
