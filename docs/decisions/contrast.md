# 明るい配色の文字と背景の色の差

`src/styles/theme.css` の明るい配色について、文字と背景の組の差（WCAG 2.x の相対輝度の比）を計算し直した表です。基準は WCAG の AA で、文字は 4.5:1 以上、入力欄の枠線は 3:1 以上です。ダークモードはまだ無いので、この表に含めません。

計算は相対輝度 `L = 0.2126R + 0.7152G + 0.0722B`（R、G、B は sRGB を線形に直した値）で、比は `(明るい方の L + 0.05) / (暗い方の L + 0.05)` です。

| 組 | 文字・線の色 | 背景の色 | 比 | 基準 |
|---|---|---|---|---|
| 本文 | `--text` `#1a1d21` | `--bg` `#f6f5f1` | 15.50 | 4.5 以上 |
| 本文（白の面） | `--text` `#1a1d21` | `--surface` `#ffffff` | 16.91 | 4.5 以上 |
| やや薄い本文 | `--text-2` `#3f444b` | `--bg` `#f6f5f1` | 9.00 | 4.5 以上 |
| 補足 | `--muted` `#5e6168` | `--bg` `#f6f5f1` | 5.69 | 4.5 以上 |
| 補足（白の面） | `--muted` `#5e6168` | `--surface` `#ffffff` | 6.20 | 4.5 以上 |
| リンク、枠線ボタンの文字 | `--accent` `#0b5f7a` | `--bg` `#f6f5f1` | 6.57 | 4.5 以上 |
| リンク（白の面） | `--accent` `#0b5f7a` | `--surface` `#ffffff` | 7.16 | 4.5 以上 |
| 青いボタンの文字 | `#ffffff` | `--accent` `#0b5f7a` | 7.16 | 4.5 以上 |
| 青いボタンの文字（hover） | `#ffffff` | `--accent-hover` `#08465a` | 10.32 | 4.5 以上 |
| コード | `--code-fg` `#f1efe8` | `--code-bg` `#1a1d21` | 14.70 | 4.5 以上 |
| 橙のボタンの文字（直す前） | `#ffffff` | `--warm` `#c2571a` | 4.49 | 4.5 以上（下回っていた） |
| **橙のボタンの文字（直した後）** | `#ffffff` | `--warm` `#b9501a` | **4.97** | 4.5 以上 |
| 橙のボタンの文字（hover、直した後） | `#ffffff` を `brightness(0.92)` | `#b9501a` を `brightness(0.92)` | 4.75 | 4.5 以上 |
| 入力欄の枠線（直す前） | `--input-line` `#9a968c` | `--surface` `#ffffff` | 2.95 | 3 以上（下回っていた） |
| **入力欄の枠線（直した後）** | `--input-line` `#8f8b81` | `--surface` `#ffffff` | **3.40** | 3 以上 |
| 入力欄の枠線（直した後、ページの背景の上） | `--input-line` `#8f8b81` | `--bg` `#f6f5f1` | 3.12 | 3 以上 |

「橙のボタンの文字（hover）」は、`filter: brightness(0.92)` が文字にもかかるため、文字の色も `#ebebeb` に暗くなる前提で測っています（直す前は 4.32 で、これも下回っていました）。

## 変えた値

- `--warm`: `#c2571a` から `#b9501a`。橙の色味は保ち、白い文字との比が 4.49 から 4.97 になります。
- `--input-line`: `#9a968c` から `#8f8b81`。入力欄の枠線と白の面との比が 2.95 から 3.40 になります。

`src/pages/og/posts/[slug].svg.ts` の OGP 画像の見出しの文字（28px の太字、`#c2571a`）は、大きい文字の基準（3:1）を満たしているので、ここでは変えていません。
