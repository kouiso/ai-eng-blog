## 否定のレビューのあとの直し（2026-11-27）

- 印刷（幅 816px の Letter など 928px 未満）では、閉じた details の中身が出ず目次が「▶ 目次」だけになっていた。印刷のときは本文の前の目次を出さず、横の欄の目次（項目の一覧）を出すようにした。Playwright の印刷の emulation で、本文の前の目次は `display: none`、横の欄の目次は `display: block` で9項目が出ることを確かめた。
- 横の欄を画面に貼り付ける `position: sticky` の境目を 900px から、横に並ぶ境目と同じ 928px にそろえた。直したあとも上の表の位置（390・927・928・1440）は同じ値だった。
